# DropShare – Frontend

Minimal web application for secure, one-time sharing of text, links, and files using short access codes.

After retrieval, content is permanently deleted.

## Tech Stack

- Next.js 16 (App Router)
- React
- Suspense (for client-side routing hooks)
- Fetch API
- Custom CSS

## Features

- Share text with auto-expiration
- Share links with one-time access
- Upload files (temporary storage)
- Code-based retrieval
- Production deployment-ready build
